# Traffic Sign Recognition using CNN on FPGA

## Project Description
This project implements a Convolutional Neural Network (CNN) to classify traffic signs using FPGA and Verilog.

The system uses the German Traffic Sign Recognition Benchmark (GTSRB) dataset to recognize different traffic sign categories.

## Objectives
- Develop a CNN model for traffic sign classification.
- Preprocess traffic sign images into 32x32 pixels.
- Test the CNN algorithm using Python.
- Implement the trained CNN model using Verilog.
- Simulate the design using ModelSim or Quartus.

## Dataset
Dataset: German Traffic Sign Recognition Benchmark (GTSRB)

- Original image dataset.
- Selected traffic sign categories.
- Image resolution: 32x32 pixels.
- Input format: Grayscale.

## Project Structure
- dataset/: Traffic sign image dataset.
- python/: CNN training and testing algorithms.
- verilog/: FPGA implementation using Verilog.
- results/: Model accuracy and simulation results.
